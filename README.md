### Run Web Dashboard

Create a new Codespace after pushing these changes. For an existing Codespace, run **Codespaces: Rebuild Container** first.

Then run:

```sh
java -cp bin com.honeypot.app.WebDashboardApp
```

The Codespace forwards port 8000 and opens the dashboard automatically.
